Configurar armazenamento em nuvem

Este site pode usar o Supabase para login e sincronização entre dispositivos. Crie um projeto Supabase, execute o arquivo SQL incluído neste pacote e informe aqui a URL do projeto e a chave pública/anon (publishable). Nunca use a chave service_role no navegador.

Como funciona a sincronização

  1. Publique o arquivo como index.html no GitHub Pages.
  2. Configure o Supabase e execute o SQL fornecido.
  3. Insira URL e chave pública nas configurações deste site.
  4. Crie uma conta com e-mail e senha e confirme o e-mail, se solicitado.
  5. Em cada dispositivo, use a mesma conta e clique em “Carregar registros da nuvem”.
  6. Exporte um backup JSON periodicamente. A nuvem não substitui o backup.

Atenção: os registros ficam vinculados à conta autenticada. O envio de registros locais para a nuvem mescla registros pelo identificador e pode sobrescrever uma versão de mesmo identificador. Antes de mesclar, faça backup.

Cuidados éticos essenciais

  • Não registrar dados pessoais ou clínicos que identifiquem usuários.
  • Não copiar prontuários, evoluções ou documentos internos.
  • Não publicar situações reconhecíveis mesmo sem nome.
  • Confirmar com os professores o enquadramento ético e autorizações aplicáveis.
Ferramenta pessoal de estudo. Não substitui prontuário, normas institucionais, supervisão docente ou avaliação ética formal. O GitHub hospeda a interface; Supabase, quando configurado, armazena os registros na nuvem.
